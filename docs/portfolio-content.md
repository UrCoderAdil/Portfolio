# Portfolio content

Works contains the original three projects plus five GitHub-linked additions. Each addition includes a summary, technologies, and implementation highlights reviewed against repository source on October 5, 2026. No new deployment is required.

## FashionStyler

A personal styling application that combines photo analysis with explainable outfit recommendations tailored to body shape, seasonal colors, and style preferences.

https://github.com/UrCoderAdil/FashionStyler

- Ranks outfits using visual embeddings, body compatibility, color analysis, and preference scoring.
- Connects a React lookbook to a Python API, with pose-guided garment overlays and shareable style cards.

## PipeForge

A full-stack platform for composing pipelines, tracking executions, and managing machine learning experiments and model versions through a unified dashboard.

https://github.com/UrCoderAdil/PipeForge

- Streams stage status and execution logs through an event-driven backend.
- Organizes pipeline execution with factory, decorator, and state patterns; includes CI workflows and container configuration.

## Sign Language Translator

A computer vision prototype that extracts hand landmarks and classifies static signs, exposing predictions through image uploads and a streaming API.

https://github.com/UrCoderAdil/SignLanguage_Translator

- Pairs landmark feature extraction with a persisted Random Forest classifier and confidence scores.
- Includes data collection and training tools, WebSocket classification, and English-to-gloss helpers; recognition requires a trained model.

## ShadowCaster

An interactive browser game that turns webcam-captured hand shadows into controls for a procedural world, blending computer vision with real-time rendering.

https://github.com/UrCoderAdil/ShadowCaster_Game

- Uses contour geometry and temporal smoothing to recognize hand-shadow shapes.
- Separates camera calibration, gesture processing, world simulation, rendering, and audio into dedicated modules.

## WhatsApp Business Assistant

A multi-tenant WhatsApp assistant that connects conversational AI to business knowledge, customer profiles, and operational tools, with a web administration dashboard.

https://github.com/UrCoderAdil/WA_bot

- Combines tenant-specific prompts, conversation memory, knowledge lookup, and human handoff.
- Provides tool-based workflows for order status and appointments, with sandbox integrations for development.
